# XYZ TACTICAL — maquette premium pédagogique

Palette premium : blanc, beige, noir et doré. Panier en panneau latéral avec liste d'articles et résumé séparé, inspiré de la structure générale de la page panier de référence.

Le catalogue de démonstration est limité aux vêtements, accessoires de protection et équipements outdoor non réglementés.

## Lancer
Ouvrir `index.html` dans un navigateur ou utiliser Live Server dans VS Code.

## Personnaliser
Les produits sont définis dans `script.js`. Les images et descriptions sont des espaces réservés à remplacer par vos contenus d'équipements outdoor autorisés. Trois emplacements d'images par produit sont prévus dans la structure de données.

## Limites
- Le formulaire e-mail enregistre localement dans le navigateur uniquement.
- Le panier utilise localStorage.
- Le bouton Telegram copie un récapitulatif de démonstration puis ouvre le profil Telegram configuré dans `script.js`.
- Le bloc paiement est une simulation pédagogique : pas d'adresse de portefeuille, de QR code ou de transfert crypto.
- Pas de backend, base de données ou traitement de paiement réel.
